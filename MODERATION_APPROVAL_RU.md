# Ручное одобрение ссылок и файлов

Версия Security v2.2 добавляет карантин сообщений.

## Как это работает

1. Пользователь отправляет внешнюю ссылку или проверяемый тип файла.
2. Бот проверяет объект через VirusTotal и локальные признаки.
3. Подтверждённая вредоносная угроза удаляется автоматически, как раньше.
4. Сообщение, требующее ручного решения, быстро удаляется из общего канала.
5. В закрытом канале безопасности появляется карточка с кнопками:
   - ✅ **Одобрить** — бот публикует сохранённый текст и файлы обратно;
   - ❌ **Отклонить** — сохранённая копия окончательно удаляется.
6. Решение может принять только администратор, пользователь с правами Manage Guild / Manage Messages / Moderate Members либо участник с одной из настроенных ролей тревоги.

## Права бота

Обязательные:

- View Channels;
- Send Messages;
- Read Message History;
- Manage Messages;
- Attach Files;
- Embed Links;
- Moderate Members.

Рекомендуемое дополнительное право:

- **Manage Webhooks** — позволяет опубликовать одобренное сообщение с именем и аватаром исходного автора. Без этого права бот всё равно опубликует сообщение, но от своего имени с явной подписью автора.

## Хранение

Очередь решений хранится в существующей базе `data/bot.sqlite3` в отдельной таблице. Временные копии файлов хранятся в `data/security_pending` и удаляются после одобрения или отклонения.

Старая статистика пользователей не изменяется. При одобрении сообщение засчитывается автору в статистику сообщений.

## Важное ограничение Discord

Бот получает событие только после того, как Discord уже принял сообщение. Поэтому сообщение может мелькнуть в канале на долю секунды до удаления. Бот не может восстановить его как настоящее сообщение пользовательского аккаунта. При наличии Manage Webhooks публикация визуально использует имя и аватар автора, но технически остаётся сообщением вебхука с отметкой о модерации.
