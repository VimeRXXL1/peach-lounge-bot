# Discord Server Bot — v3 profile/xp/embed

## Главное в этой версии
- `/profile` теперь отправляет только картинку профиля без embed-текста.
- В карточке профиля роли отображаются через `config.json`, поэтому роли из ваших категорий и XP-роли показываются с emoji/названиями.
- Добавлены XP-роли за голосовые уровни 1/5/10/.../100.
- Формула XP настроена под голосовые: `xp_for_level = 60 * level^2`.
- При `5 XP/мин`: 5 уровень ≈ 5 часов, 10 ≈ 20 часов, 50 ≈ 500 часов, 100 ≈ 2000 часов.
- Добавлены готовые embed-шаблоны: `/embed_templates`, `/embed_template_send`.

## XP в голосовых
Команды:
- `/voice_xp_config` — посмотреть настройки
- `/set_voice_xp` — изменить XP/мин, монеты/мин, минимум людей в ГС
- `/list_level_roles` — посмотреть роли за уровни
- `/set_level_role` — добавить/изменить роль за уровень
- `/remove_level_role` — удалить роль за уровень

По умолчанию:
```json
"voice_xp": {
  "xp_per_minute": 5,
  "coins_per_minute": 1,
  "min_members_in_channel": 2
}
```

## Готовые embed-шаблоны
Команды:
- `/embed_templates` — список шаблонов
- `/embed_template_send template:<ключ> channel:<канал>` — отправить готовый embed
- `/embed_send` — создать ручной embed без шаблона

Шаблоны лежат в `config.json` в блоке `embed_templates`.
Доступны подстановки: `{server}`, `{count}`, `{member}`, `{user}`, `{bot}`.

## Профиль
Команда:
- `/profile`

Показывает только картинку с:
- аватаркой
- уровнем
- XP
- балансом
- топом
- временем в ГС
- датой входа
- датой создания аккаунта
- ролями со смайлами из конфига
- отношениями/связями
- текущим фоном

## Важно
- Роль бота должна быть выше ролей, которые он выдаёт.
- В Discord Developer Portal включи `SERVER MEMBERS INTENT`.
- Для профиля нужны права `Send Messages`, `Attach Files`, `Embed Links`.
- Для ролей нужны `Manage Roles` и правильная иерархия ролей.
- Silver роль всё ещё стоит `role_id: 0`, потому что ранее был указан ID Gold.
