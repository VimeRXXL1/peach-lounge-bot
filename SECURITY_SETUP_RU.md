# Peach Lounge — защита от спама, ссылок и взломанных аккаунтов

## Как теперь работает защита

Бот не блокирует все ссылки и программы подряд. Решение делится на три уровня:

1. **Подтверждённая угроза или массовый спам** — бот удаляет недавнюю рассылку пользователя, выдаёт тайм-аут и пингует модераторов/администраторов.
2. **Подозрительная или неизвестная ссылка/программа** — сообщение остаётся, но в закрытый канал приходит тревога с автором, каналом, безопасно обезвреженной ссылкой, SHA-256 файла и результатом проверки.
3. **Проверенная ссылка без обнаруженных угроз** — сообщение остаётся. Для внешних сайтов бот также может отправить запись модерации; повторные одинаковые уведомления ограничены таймером.

Одна эвристика вроде слов `free nitro`, расширения `.exe` или необычного домена **не является основанием для автоматического удаления**. Она только повышает подозрительность и зовёт модерацию. Автоматическое удаление ссылки/файла выполняется только при подтверждении репутационным сервисом либо при явном массовом спаме.

## Что отслеживается

- быстрый флуд;
- одинаковые сообщения;
- одна и та же ссылка, рассылаемая несколько раз;
- рассылка по нескольким текстовым каналам;
- сообщения в текстовых чатах голосовых каналов;
- массовые упоминания;
- ссылки после редактирования старого сообщения;
- частые входы, выходы и переходы между голосовыми каналами;
- приложения и архивы без автоматической блокировки только по расширению;
- ссылки через Google Safe Browsing и, дополнительно, VirusTotal;
- вложения через поиск готового отчёта VirusTotal по SHA-256.

Бот **не слушает и не распознаёт разговоры пользователей в голосовом канале**. Он видит только Discord-события входа/выхода/перехода и сообщения в прикреплённом текстовом чате голосового канала.

## Репутационные сервисы

В `.env` добавь:

```env
SAFE_BROWSING_API_KEY=твой_ключ_google
VIRUSTOTAL_API_KEY=твой_ключ_virustotal
```

После изменения переменных окружения перезапусти бота и проверь `/antispam_status`.

### Google Safe Browsing

Используется как основная проверка вредоносных и фишинговых URL. При режиме `urls.search` полный адрес отправляется в Google для проверки. Не публикуй в Discord ссылки с секретными токенами, приватными параметрами авторизации или персональными данными.

### VirusTotal

- Для URL бот запрашивает уже существующий отчёт и не отправляет неизвестную ссылку на новый публичный анализ.
- Для вложений бот скачивает файл из Discord только в память, считает SHA-256 и ищет уже существующий отчёт VirusTotal.
- Бот не запускает файл и по умолчанию не загружает неизвестные файлы в VirusTotal.
- Если файл или URL ещё неизвестны сервису, бот оставляет сообщение и зовёт модерацию вместо автоматического удаления.

## Установка обновления

1. Сохрани старые `.env`, `config.json` и папку `data`.
2. Загрузи файлы новой версии на хостинг.
3. Установи зависимости из `requirements.txt`.
4. Добавь ключи репутационных сервисов в `.env`.
5. Перезапусти бота.

Не удаляй `data/bot.sqlite3`, иначе потеряется статистика.

## Права бота

Обязательные:

- View Channels;
- Send Messages;
- Read Message History;
- Manage Messages;
- Moderate Members;
- Embed Links.

Для отключения голосового спамера дополнительно нужно **Move Members**.

Роль бота должна находиться выше ролей пользователей, которым он должен выдавать тайм-аут. Право Administrator боту не требуется.

## Первая настройка

Создай закрытый канал, например `#security-logs`, затем выполни:

```text
/antispam enabled:true timeout_minutes:60 log_channel:#security-logs moderator_role:@Модераторы administrator_role:@Администраторы
```

Проверь состояние:

```text
/antispam_status
```

Проверь конкретную ссылку вручную:

```text
/security_check link:https://example.com
```

## Что происходит при срабатывании

### Массовый спам

По умолчанию срабатывает при следующих порогах:

- 6 сообщений за 8 секунд;
- 3 одинаковых сообщения за 35 секунд;
- одна ссылка в 3 сообщениях за 45 секунд;
- 4 сообщения минимум в 3 каналах за 12 секунд;
- 5 и более упоминаний.

Бот удаляет до 25 недавних сообщений нарушителя за 90 секунд, выдаёт тайм-аут на 60 минут и отправляет тревогу.

### Обычная одиночная ссылка

Бот проверяет репутацию. Если вредоносность не подтверждена, сообщение не удаляется. Модерация получает уведомление с результатом проверки, кроме доверенных доменов из `trusted_domains`.

### Программа или архив

Файл не удаляется только из-за `.exe`, `.apk`, `.zip`, `.rar` и подобных расширений. Бот вычисляет SHA-256 и проверяет готовый отчёт VirusTotal:

- подтверждённая вредоносность — удаление и тайм-аут;
- подозрительный или неизвестный результат — файл остаётся, модерация получает тревогу;
- чистый готовый отчёт — файл остаётся, результат фиксируется.

### Голосовые каналы

- Сообщения в текстовом чате голосового канала проверяются как обычные сообщения.
- При 6 входах/выходах/переходах за 30 секунд бот может отключить пользователя от голосового канала, дать тайм-аут на 10 минут и пингануть модерацию.

## Экстренная очистка после взлома

```text
/purge_user member:@участник minutes:1440
```

Команда проверяет обычные текстовые каналы, активные ветки и текстовые чаты голосовых каналов.

Дополнительно:

1. Выдай аккаунту тайм-аут.
2. Временно сними опасные роли.
3. Предупреди участников не открывать уже отправленные ссылки и файлы.
4. Владельцу аккаунта нужно сменить пароль, завершить неизвестные сеансы, удалить неизвестные Authorized Apps, включить 2FA и проверить устройство.

## Настройки в `config.json`

Главные параметры блока `antispam`:

- `alert_on_external_link` — сообщать о внешних ссылках;
- `trusted_domains` — домены, для которых не нужна обычная зелёная тревога;
- `auto_delete_malicious_links` — удалять подтверждённые вредоносные ссылки;
- `auto_delete_malicious_attachments` — удалять подтверждённые вредоносные вложения;
- `virustotal_malicious_threshold` — минимальное количество детектов VirusTotal для автоматического действия;
- `review_attachment_extensions` — расширения, которые отправляются на репутационную проверку;
- `voice_hop_protection` — защита от спама переходами по голосовым;
- `ignored_channel_ids`, `ignored_role_ids`, `ignored_user_ids` — исключения.

Не добавляй обычные роли администрации в исключения без необходимости: их аккаунты тоже могут быть взломаны.
